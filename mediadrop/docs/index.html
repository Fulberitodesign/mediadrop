MediaDrop

Un panneau flottant pour parcourir vos dossiers, préécouter vos sons et glisser-déposer directement vos fichiers dans Premiere Pro (ou n'importe quel autre logiciel) — sans passer par l'explorateur de fichiers.

Télécharger pour WindowsInstalleur .exe Télécharger pour MacInstalleur .dmg (Intel & Apple Silicon)

Fonctionnalités

Bibliothèque de dossiers
Ajoute n'importe quel dossier de ton ordinateur, il reste enregistré d'une session à l'autre.
Préécoute audio
Forme d'onde, lecture au clic, barre de progression, volume, raccourci Espace.
Aperçu vidéo
Miniature extraite automatiquement, lecteur en grand en un clic.
Glisser-déposer natif
Dépose le fichier directement dans la timeline de Premiere Pro ou tout autre logiciel.

Installation

Windows : si "Windows a protégé votre ordinateur" apparaît, clique sur Informations complémentaires puis Exécuter quand même. C'est normal pour une petite application non certifiée par Microsoft (le certificat coûte cher) — MediaDrop ne contient aucun logiciel malveillant, le code est visible sur GitHub.
Mac : si "MediaDrop ne peut pas être ouvert" apparaît, va dans Réglages Système → Confidentialité et sécurité, fais défiler jusqu'en bas et clique sur Ouvrir quand même.
